# 发行验收

## 自动回归

`npm test` 覆盖：

- 非固定节拍与任意秒数输入，生成和重生成不增加判定。
- 确定性词云、歌词重复密铺、字号层次、完整原歌词、道路间隙、两球同速、分合端点。
- 整段手动命中、双押 80ms、重复触点、取消、暂停清理、不同岔路同分。
- 音乐暂停位置、全曲尾部、独立音量、源码设置迁移与纪录资格。
- ZIP 往返、仅谱面导出、损坏档案、资源校验、IndexedDB 恢复及未持久保存。

## 浏览器流程

导入独立音乐 → 粘贴普通歌词/LRC → 录制含双押的片段 → 撤销吸附 → 生成 → 试玩 → 保存 → 刷新 → 重新打开 → 导出 → 新会话导入 → 核对音乐、文字、路线及时间。

检查目录搜索/收藏/最近、翻页拖动和按钮、三个创作模板、版本副本、触点切换、暂停→设置→继续、旋转、后台切换、离线重新打开、JSON 导入和附加音乐。

## 视口与实机

视口：320×568、390×844、844×390、1024×768。身体页面不得滚动；书页和编辑器可在自己的内容区滚动，演奏区域不得滚动。字形完整、输入控件可达，横屏没有遮挡。

实际设备目标：iPhone Safari、Android Chrome、iPad Safari、桌面 Chrome。每台设备记录系统/浏览器版本、屏幕刷新率、输入到声音/光效的观察、平均和 P95 绘制耗时、实际帧率。至少完成双球交替、双押和一个岔路段落。减少动态效果关闭脉冲动画；触觉以设备支持为准。

新玩家验收：不阅读开发文档，10 分钟内完成一首音乐的片段录谱、生成、试玩与谱包互换；教学后能正确识别接下来三个操作。

没有实际设备或外部新玩家时，记录为待验收，不能用模拟视口或自动 PERFECT 代替真机与可用性结论。

## 2026-10-05 本次记录

环境：macOS、Codex 内置浏览器、Node.js 26.4.0。以下是桌面浏览器及尺寸模拟的观察，不能作为 iPhone、Android 或 iPad 真机结论。

- 本地包含旧曲资源时，4 个测试文件、43 项测试通过；独立源码 ZIP 解压后 `npm ci`、格式检查、39 项测试、TypeScript/Vite 构建及公开 Schema 校验通过。源码包不包含《反乌托邦》音乐或歌词。
- 使用真实键盘输入完成「同拍双押」40 次判定、7 次双押，1000 分、40 PERFECT、0 MISS；「分合与岔路」选择右侧路线后同样获得 1000 分和 40 PERFECT。后者期间后台自动暂停，续播后完成。
- 实际录制 14 个非吸附节奏点（其中 3 个双押），撤销节拍吸附恢复原始时间；生成双球构图并保存「雨后的字缝 / 本机试作」。刷新后恢复草稿与作品，下载 ZIP 包后在独立来源会话导入，标题、署名、14 个判定、文字及音乐均恢复并可演奏。
- 本地服务器停止后重新加载页面，仍可打开曲库并播放已导入作品；设置中确认程序与宋体字库已缓存。暂停→设置→返回→续播、旋转自动暂停均在界面观察到正确状态。
- 检查 320×568、390×844、844×390、1024×768；书页/编辑器内部滚动，外层页面保持固定。短竖屏的演奏入口在内部滚动后可达，横屏对页的入口完整可见。
- 词云更新前的一次桌面练习的诊断读数为平均绘制 0.16ms、P95 0.40ms、约 60 FPS、事件送达 P95 0.20ms。事件送达是浏览器事件分发耗时，不包含触屏硬件、音频输出与屏幕显示延迟。
- `npm audit` 未发现已知依赖漏洞；源码 ZIP 按固定时间戳打包，两次输出逐字节相同。

词云更新：允许重复歌词，用五档填缝字号与重点大词铺满路线周围。新增覆盖率回归：抽样视野中，除道路外的字形方框覆盖率超过 50%；原歌词保留，通路无字形相交。书页使用非线性错峰显影，游戏不改变音乐时间或球速。

仍待人工验收：四种指定实机的输入/声画延迟及触觉体验、另一台实体设备的谱包互换、外部新玩家 10 分钟创作测试。不要把这些列为已通过。
